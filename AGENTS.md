# AGENTS.md — інструкції для ШІ-асистентів

Робоча угода для всіх ШІ-агентів (Claude, Gemini, Codex, Copilot тощо) у репозиторії **Webcassonne**. `CLAUDE.md` і `GEMINI.md` лише імпортують цей файл; усі правила пишемо тут.

---

## 1. Суть проєкту

- **Що це:** вебзастосунок, що емулює базову настільну гру «Carcassonne» з онлайн-мультиплеєром у браузері та автоматичним підрахунком очок.
- **Для кого:** «Організатор віддаленого вечора» — збирає друзів з різних міст на партію під голосовий дзвінок, правила знає сам. Продукт не навчає правилам.
- **Цикл:** створити кімнату → запросити за посиланням → почати партію → ходи (тайл → міпл) → автоматичний підрахунок → фінальна таблиця.
- **Контекст:** навчальний проєкт, 3 людини, один семестр. Наприкінці — живе демо повної партії 2–5 гравців.
- **Стан:** Walking Skeleton. Є `GET /api/health`, сторінка-заглушка, сховище в пам'яті. Ігрової логіки й історій ще немає — вони реалізуються по одній.

## 3. Стек

- **Бекенд:** Go 1.26, `net/http` (`http.ServeMux`). WebSocket — `github.com/coder/websocket`, додається з US-04.
- **Фронтенд:** React 19 + TypeScript (strict) + Vite, лінтер oxlint. Поле — SVG без бібліотек.
- **Сховище:** пам'ять процесу (`server/internal/store`), бази даних немає ([ADR-0004](docs/adr/0004-in-memory-storage.md)).
- **Тести:** `go test` (табличні тести).

Нова технологія або бібліотека (БД, router, state-менеджер, UI-кіт, Socket.IO, веб-фреймворк) — рішення команди через новий ADR. Пропонуй, не впроваджуй.

## 4. Структура

```text
docs/                    документація і контракти (див. §2)
prompts/                 промпти етапів курсу
server/                  Go-модуль github.com/EndlessNN/Webcassonne/server
  cmd/server/            main: роутер + роздача web/dist; PORT (8090), WEB_DIR (../web/dist)
  internal/httpapi/      REST/WS-обробники, єдиний формат помилок (errors.go)
  internal/model/        структури з docs/data-model.md, без логіки
  internal/store/        сховище кімнат у пам'яті
  internal/room/         (майбутнє) кімнати, лобі, черга ходу
  internal/game/         (майбутнє) чисті правила: тайли, стикування, об'єкти, підрахунок
web/                     React + TS + Vite
  src/api/               types.ts (дзеркало docs/api.md), client.ts
  src/App.tsx            заглушка з перевіркою /api/health
```

Залежності лише в один бік: `httpapi` → `room` → `game` → `model`. `store` знає лише `model`. `game` не знає про мережу, кімнати й сховище.

## 5. Команди

```bash
# Запуск усього (з кореня): зібрати UI, підняти сервер на http://localhost:8090
npm --prefix web install && npm --prefix web run build
go -C server run ./cmd/server

# Dev-режим UI з гарячим перезавантаженням (другий термінал; /api проксіюється на :8090)
npm --prefix web run dev            # http://localhost:5173

# Перевірки
go -C server test ./...
go -C server vet ./...
gofmt -l server                     # має нічого не вивести
npm --prefix web run lint
npm --prefix web run build          # включає tsc
```

`go test -race` потребує cgo (gcc). На Windows без gcc запускай без `-race`.

Перед тим як сказати «готово», запусти перевірки зміненої частини і чесно повідом результат.

## 6. Правила кодогенерації

### Загальні
- Ідентифікатори й коміти — англійською. Коментарі, документація й тексти UI — українською.
- Терміни глосарію, без синонімів:

  | Українською | У коді |
  |---|---|
  | тайл / тип тайла / стопка | `PlacedTile` / `TileType` / `Deck` |
  | міпл | `Meeple` |
  | дорога / місто / щит / монастир / поле | `Road` / `City` / `Pennant` / `Monastery` / `Field` |
  | об'єкт / сегмент | `Feature` / `Segment` |
  | кімната / організатор / гравець | `Room` / `Host` / `Player` |
  | хід / фаза / обертання | `Turn` / `Phase` / `Rotation` |

- Одна задача = одна історія `US-XX`. Згадуй її в назві тесту й коміті (`feat(US-03): join room by link`).
- Найменша зміна, що закриває історію. Не рефактори сусідній код без прохання.

### Сервер (Go)
- **Сервер — єдине джерело правди.** Валідує кожну дію, рахує очки, розсилає `room_state`.
- Помилки — лише через `writeError` у форматі `docs/api.md` §1 і лише з кодами з таблиці там.
- `internal/game`: чисті детерміновані функції без I/O, `time.Now()` і глобального `rand` (генератор передається параметром).
- Для US-12, US-13, US-18, US-21, US-22 — **тест першим**, числа з Gherkin-сценаріїв.
- Стан кімнати змінюється лише під її м'ютексом або в одній горутині кімнати.
- Помилки повертай як `error`; `panic` у бізнес-логіці заборонено.

### Клієнт (React/TS)
- Без `any`. Типи в `src/api/types.ts` збігаються з `docs/api.md` поле в поле.
- Клієнт не вирішує, чи хід допустимий, і не рахує очки: бере `legalPlacements`, `legalMeepleSegments`, `score`, `finalScores` із сервера.
- UI показує `error.message`, а поведінку обирає за `error.code`.

### Зміна контракту
Порядок: `docs/api.md` або `docs/data-model.md` → `server/` → `web/src/api/types.ts`. Усе в одному коміті.

## 7. Інженерні заборони

- **Не вигадуй поля, повідомлення, ендпоінти й коди помилок.** Перевіряй `docs/api.md` і `docs/data-model.md`. Немає в контракті — запропонуй зміну документа й чекай згоди.
- **Не вигадуй правила гри й очікувані очки.** Джерело — `docs/requirements.md` §4. Неоднозначно — спитай.
- **Не вигадуй склад тайлів.** Лише з `docs/tiles.md`; поки його немає — зупинись.
- **Не змінюй очікувані значення в тестах, щоб тест пройшов.** І не видаляй, не пропускай (`t.Skip`, `.skip`) і не коментуй тести.
- **Не виходь за межі MVP:** без акаунтів, БД, відновлення після відключення, оновлення сторінки, чату, ботів, доповнень, рейтингу, таймерів, мобільної верстки, довідки з правил.
- **Не відправляй клієнтам** токени інших гравців і порядок стопки.
- **Не додавай залежності** (Go-модулі, npm-пакети) без погодження.
- **Не редагуй** `README.md` (дослідницькі розділи), `docs/requirements.md`, `docs/adr/` і `prompts/` без прямого прохання. Нове рішення — новий ADR, а не правка старого.
- **Не роби коміт і push без прохання**, не роби `push --force`, не переписуй історію.

## 8. Definition of Done для історії

1. Усі Gherkin-сценарії історії покриті тестами або перевірені вручну (вкажи як).
2. `go test`, `go vet`, `gofmt -l`, `npm run lint`, `npm run build` проходять.
3. `docs/api.md` і `docs/data-model.md` відповідають коду; позначка ⏳ у `api.md` змінена на ✅.
4. Звіт чесний: що зроблено, що не перевірено, що падає.
