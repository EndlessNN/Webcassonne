# ADR-0003. Бекенд: Go, `net/http` + WebSocket, один процес

- **Статус:** прийнято
- **Дата:** 2026-10-28

## Контекст

Сервер — єдине джерело правди (див. [технічний аналіз](../technical-analysis.md), заборона 8): валідує ходи, рахує очки, розсилає стан 2–5 гравцям у реальному часі (US-04, US-15). Найскладніша частина — чисті алгоритми над графом тайлів (US-12, US-13, US-18, US-21, US-22), їх треба покрити модульними тестами. Нульовий бюджет, локальний запуск. Команда обрала Go на етапі досліджень; досвід з ним є.

## Розглянуті варіанти

| Варіант | Плюси | Мінуси |
|---|---|---|
| **Go, стандартна `net/http` + бібліотека WebSocket** | Один статичний бінарник; горутина на кімнату природно серіалізує ходи; `go test` без фреймворків; стандартний роутер Go 1.22+ має методи і параметри шляху | Типи протоколу дублюються з TS вручну |
| Node.js + TS (Socket.IO) | Спільні типи з клієнтом | Команда обрала Go; правила гри в TS легко «протекли» б у клієнт |
| Go + фреймворк (Gin, Echo, Fiber) | Middleware з коробки | Для 5 ендпоінтів зайве; ще одна залежність |
| Java/Spring | Знайомо з іншого курсу | Важкий запуск, зайве для гри в пам'яті |

## Рішення

- Go 1.26, роутер `http.ServeMux` зі стандартної бібліотеки.
- WebSocket — `github.com/coder/websocket` (додається разом з першою історією, що його потребує: US-04). Стандартна бібліотека WebSocket не має.
- Один процес обслуговує `/api/*` і роздає зібраний `web/dist`. У dev-режимі Vite проксіює `/api` на Go.
- Шари: `httpapi` (REST/WS) → `room` (кімнати, черга ходу) → `game` (чисті правила). `model` — спільні структури даних, `store` — сховище.
- Порт за замовчуванням **8090** (8080 часто зайнятий Tomcat/Spring з інших курсів), змінюється змінною `PORT`.

## Наслідки

- Пакет `game` не імпортує мережу, час і глобальний `rand` — тестується табличними тестами з числами з Gherkin.
- Кожна кімната обробляє дії послідовно (одна горутина або м'ютекс), тому гонок між гравцями немає. `go test -race` потребує cgo; на Windows без gcc запускаємо без `-race`.
- Протокол дублюється: `server/internal/httpapi` і `web/src/api/types.ts`. Джерело — `docs/api.md`.
