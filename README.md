# Webcassonne
Веб-платформа, що повністю емулює фізичну копію настільної гри "Carcassonne".
### Команда
- **Панько Владислав** — AI-enabled Engineer
- **Костик Олексій** — AI-enabled Engineer
- **Кулакевич Станіслав** — SaaS B2B AI-enabled CEO
### Проблема
- Відсутність можливості зіграти у фізичну версію гри через відстань між гравцями.
- Неможливість придбати гру з фінансових або логістичних причин.
- Бажання новачків спробувати гру перед покупкою фізичної копії.
## Цільовий користувач
*   **Фанати настільних ігор**, які хочуть зручно та безперешкодно грати улюблену гру з друзями онлайн.
*   **Новачки**, яким складно одразу запам'ятати всі правила та нюанси нарахування переможних балів у фізичній версії (система робитиме це за них).
*   **Казуальні гравці**, які шукають швидкий і доступний браузерний варіант для відпочинку, без необхідності довгої реєстрації чи встановлення додаткового ПЗ.
### Рішення
Створення вебсайту-емулятора "Carcassonne", який дозволить безперешкодно грати в улюблену настільну гру онлайн.
