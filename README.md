### Проблема
- Географічні бар'єри унеможливлюють спільну гру за одним столом.
- Висока вартість фізичної копії гри та ризик "сліпої" покупки (без попереднього тестування).
- Складний, довгий та схильний до помилок ручний підрахунок очок (особливо за поля наприкінці гри).
### Рішення
